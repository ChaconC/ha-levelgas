First public release of Levelgas for Home Assistant 2026.10+.

## Features

- Monitor tank level, battery percentage, and the last sensor reading.
- Track a median-smoothed tank level that reduces isolated spikes and preserves its samples across restarts.
- Configure the polling interval, smoothing window, and sensor timezone.
- Add multiple tanks through the Home Assistant UI and sign in again through Repairs when needed.

Uses your Levelgas email and password. No MQTT broker, add-on, or connected phone is required.

## Installation

Install through a HACS/Marketplace custom repository using `https://github.com/ChaconC/ha-levelgas` and the **Integration** category. Restart Home Assistant, then add **Levelgas** under **Settings → Devices & services**.

For manual installation, extract the attached `levelgas.zip` into `/config/custom_components/levelgas/`, with `manifest.json` directly inside that directory, then restart Home Assistant.

Setup guides: [English](https://github.com/ChaconC/ha-levelgas/blob/1.0.1/README.md) · [Español (México)](https://github.com/ChaconC/ha-levelgas/blob/1.0.1/README.es-MX.md).

## Sensor behavior

The default five-reading median reduces isolated spikes but takes three new readings to reflect a refill once the window is full. Recent API history initializes the filter; Home Assistant Recorder history starts at installation. The sensor timezone defaults to `America/Mexico_City` and can be changed in the integration options.
