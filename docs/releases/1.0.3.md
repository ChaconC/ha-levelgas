Fix timezone database lookups that could block Home Assistant's event loop while polling Levelgas.

The integration now resolves the configured timezone asynchronously during setup and reuses that timezone object for current readings and smoothing history. Existing saved history remains compatible, and changing the sensor timezone still reseeds the smoothing buffer.

Regression tests cover cold timezone caches during setup and refresh, correct timestamp offsets and smoothing, and invalid configured timezones.

Requires Home Assistant 2026.10 or later.
