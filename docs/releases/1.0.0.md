Initial native Levelgas integration for Home Assistant 2026.10+.

Adds tank level, battery, last-reading time and a median-smoothed tank level to
Devices & services. Polls every two hours by default. The configurable smoothing
window counts distinct sensor readings and persists across restarts.

Install using a HACS/Marketplace custom repository of type Integration, then add
Levelgas under Devices & services. Uses Levelgas email/password authentication.
No MQTT broker, add-on, or connected phone is required.

The default five-reading median rejects isolated spikes but delays real refills.
Historical API points initialize the filter; HA Recorder history starts at installation.
